# Avito AI Assistant

AI-ассистент для улучшения объявлений на Авито. Помогает продавцам создавать качественные описания и определять рыночную цену.

## 🚀 Технологии

- **React 19** + **TypeScript**
- **Vite** — сборка
- **React Router v7** — маршрутизация
- **Redux** — управление состоянием
- **TanStack Query** — работа с серверными данными
- **Material UI** — компоненты интерфейса
- **Ollama** — интеграция с LLM

## Что изменено в сервере

1. **Порт** — исправлен регистр: `process.env.port` → `process.env.PORT`
2. **ID** — добавлен `id` в ответ `GET /items`
3. **CORS** — добавлена обработка OPTIONS-запросов

## 📦 Установка и запуск

1. **Установите Ollama** (https://ollama.com/download)
2. **Скачайте модель:** `ollama pull llama3.2:3b`
3. **Запустите сервер Ollama:** `ollama serve` (в отдельном терминале)
4. **Запустите бэкенд** (из вашего репозитория, правки я указал какие по серверу сделал)
5. **Запустите фронтенд:** `npm run dev`
6. **Откройте:** `http://localhost:5173/ads`

### Требования
